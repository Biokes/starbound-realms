# Architecture Decision Records (ADRs)

This directory contains architecture decision records (ADRs) for significant decisions made in Starbound Realms. Each ADR documents:

- **What** was decided
- **Why** it was decided
- **When** the decision was made
- **Trade-offs** considered
- **Consequences** of the decision

## Why ADRs?

Decisions often live only in PR history or Slack messages, making them invisible to new contributors. ADRs ensure we have a searchable, permanent record of *why* the codebase looks the way it does.

## Format

Each ADR follows [MADR 3.0](https://adr.github.io/madr/) (Markdown Architectural Decision Records).

See [ADR Template](adr-template.md) for the format.
